# The Legit Rank

**The truth before you buy.** The independent review platform for Malawi and Africa.

Check real buyer ratings, read honest reviews, and buy from verified sellers on WhatsApp and Facebook.

## Stack

- Static landing page (pure HTML/CSS/JS, no build step)
- Bilingual: English / Chichewa toggle
- Deployed via Coolify on brandfletch infrastructure

## Deploy

Any static file server works. The site is a single `index.html`.
